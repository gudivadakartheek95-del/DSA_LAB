# Data Structures and Algorithms - Lab Manual (23CSE203)

Python programs for the DSA lab, organised week by week.
Every program is menu-driven / takes user input and runs with plain Python 3 (no extra libraries).

```bash
python Week-01_Recursion/1a_countdown_launch.py
```

| Week | Topic | Folder | Programs |
|------|-------|--------|----------|
| 1 | Recursion | `Week-01_Recursion` | Countdown + launch, P^n growth factor, Fibonacci, recursive employee-ID search, factorial for parcels |
| 2 | Searching | `Week-02_Searching` | Linear Search, Binary Search (sorted vs unsorted check) |
| 3 | Elementary Sorting | `Week-03_Elementary_Sorting` | Bubble, Selection, Insertion Sort |
| 4 | Advanced Sorting | `Week-04_Advanced_Sorting` | Merge Sort, Quick Sort |
| 5 | Linked Lists | `Week-05_Linked_Lists` | Singly, Doubly, Circular Linked List (create, insert begin/end/index, delete by value / prior node / last, count, display) |
| 6 | Stacks | `Week-06_Stacks` | Stack using Array, Stack using Linked List |
| 7 | Queues | `Week-07_Queues` | Queue (Array), Queue (Linked List), Circular Queue (Array), Circular Queue (Linked List) |
| 8 | Binary Trees | `Week-08_Binary_Trees` | Binary Tree using Array, using Linked List |
| 9 | Binary Search Trees | `Week-09_Binary_Search_Trees` | BST insert, delete, search, traversals, min/max, height |
| 10 | AVL Tree | `Week-10_AVL_Tree` | AVL Tree with all rotations, insert, delete, search, traversals |
| 11 | Hashing | `Week-11_Hashing` | Separate chaining, Linear probing, Quadratic probing |
